# Excursion

Excursion is a landing page project that advertises a mobile app for recording and sharing travel experiences. This project was built using HTML and CSS as part of a Codecademy course. The page features a video, images, and a clean, responsive design to showcase the app's features.

# Installation

1. Clone the repository:
   git clone
https://github.com/Psc30/excursion.git

2. Open the 'index.html' file in your web browser.

## Usage

Open 'index.html' in your web browser to view the Excursion landing page. Explore the features and design as shown in the Codecademy project.
